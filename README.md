## Overview
This repository maintains a blocklist of CIDR ranges that have engaged in cyber attacks or preparatory activities (e.g., port scanning, reconnaissance, brute-force attempts) against affiliated servers.

### Policy & Scope
- Entries are documented in **CIDR blocks** rather than single IP addresses.
- Because entire subnets are targeted, this list may encompass a broader range than strictly necessary (potential false positives).
- This approach is taken intentionally to block network segments that permit, host, or fail to mitigate malicious activity.
